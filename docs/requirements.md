# 产品需求

## 目标

用户在一台 Windows 电脑上管理同一局域网内的已知电脑，能从任务栏的通知区域打开列表，查看电脑是否可达，并按需唤醒一台或多台电脑。交付为单个 Windows x64 EXE，双击即可打开。

| 编号 | 需求 | 验收方式 |
| --- | --- | --- |
| R1 | 程序运行后在 Windows 通知区域注册 Nwake 图标。单击图标或右键选择「打开电脑列表」可打开列表；关闭列表不退出。 | 在有 Explorer 托盘的 Windows 用户会话中验证打开、关闭、重新打开及右键退出。 |
| R2 | 可添加和编辑已知电脑，也可逐台或批量移除。主机名、IPv4 和 MAC 地址保存于 EXE 同级的 `hosts.json`。每个 IPv4 和 MAC 地址只能录入一次。 | 批量移除先确认设备和数量，再一次保存。重启后列表保持。从其他工作目录启动时仍读取 EXE 同级配置。非法地址和重复记录提示修改，错误配置保留供修复。 |
| R3 | 列表显示主机名、IPv4 和状态。点击「刷新」才检测在线状态。 | 打开窗口、增删设备和发送唤醒包均无自动检测。手动刷新后，收到 Ping 回复显示「在线」，未收到回复显示「无响应」，检测出错另行提示。 |
| R4 | 可勾选一台或多台电脑发送 Wake-on-LAN Magic Packet。 | 只向勾选目标发送，确认批量范围，分别报告成功交给系统和发送失败的台数。状态仍由探测结果决定。 |
| R5 | 在 Windows x64 上运行单个 EXE，普通用户不需要另外安装 Python。 | 将 EXE 复制到空目录后启动，验证托盘及窗口正常。 |
| R6 | 点击「扫描局域网」后自动扫描一个可用的本地 IPv4 网段，显示设备的 IPv4 和 MAC，并尝试获取主机名。 | 可以切换网段或停止扫描。勾选设备的主机名查完后可一次添加，也可停止后按 IP 添加。重扫时恢复仍匹配的勾选。已有 IPv4 或 MAC 会跳过，保存失败时保留勾选。 |

最多管理 64 台电脑。设备可从扫描结果添加，也可手动录入。范围为同一局域网内的检测和唤醒。
