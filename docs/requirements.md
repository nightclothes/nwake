# 产品需求

## 目标

用户在一台 Windows 电脑上管理同一局域网内的已知电脑，能从任务栏的通知区域打开列表，查看电脑是否可达，并按需唤醒一台或多台电脑。交付为单个 Windows x64 EXE，双击即可打开。

| 编号 | 需求 | 验收方式 |
| --- | --- | --- |
| R1 | 程序运行后在 Windows 通知区域注册 Nwake 图标。单击图标或右键选择「打开电脑列表」可打开列表；关闭列表不退出。 | 在有 Explorer 托盘的 Windows 用户会话中验证打开、关闭、重新打开及右键退出。 |
| R2 | 可添加、编辑、移除已知电脑，保存主机名、IPv4 和 MAC 地址；同一配置不允许重复 IPv4 或 MAC。 | 重启后列表保持。非法地址和重复记录提示修改，错误配置不会被自动覆盖。 |
| R3 | 列表显示主机名、IPv4、状态，打开或后台运行时定期检测，也可手动刷新。 | 对回复 Ping 的 IP 显示「在线」；没有回包显示「无响应」；检测本身出错另行提示。 |
| R4 | 可勾选一台或多台电脑发送 Wake-on-LAN Magic Packet。 | 只向勾选目标发送，确认批量范围，分别报告成功交给系统和发送失败的台数。状态仍由探测结果决定。 |
| R5 | 在 Windows x64 上运行单个 EXE，普通用户不需要另外安装 Python。 | 将 EXE 复制到空目录后启动，验证托盘及窗口正常。 |

首版最多管理 64 台电脑。目标名称和网卡地址由用户录入；不包含网段扫描、跨网段中继、远程关机、自动开机启动或云服务。目标电脑是否真正开机由其网络响应间接判断，禁止 ICMP 的电脑可能已开机但显示「无响应」。
